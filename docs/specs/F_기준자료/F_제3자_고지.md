# 최종 산출물의 제3자 고지

기준일: 2026-10-30

이 고지는 **이번에 제공하는 대화형 구성도 HTML의 런타임·내장 글꼴과 PDF의 문서용 내장 글꼴**에 적용한다. 설계에 등장하는 미구현 방화벽 제품의 전체 의존성·배포 적합성 감사나 SBOM을 대신하지 않는다. 자체 작성 설계·계약의 Apache-2.0 정책이 아래 제3자 구성요소의 라이선스를 바꾸지 않는다.

## 1. 포함 범위

| 구성요소 | 실제 사용 위치·형태 | 라이선스·권리 고지 |
|---|---|---|
| Archify 2.17.0-dev.1 standalone viewer runtime | `F_아키텍처_구성도.html`의 스타일·스크립트·상호작용 및 내보내기 코드 | MIT. 2026 tt-a1i (Archify), 2025 Cocoon AI |
| JetBrains Mono, Google Fonts 서비스 revision v24 | 위 HTML의 WOFF2 내장 subsets. cyrillic-ext·cyrillic·greek·vietnamese·latin-ext·latin | SIL Open Font License 1.1. 2020 The JetBrains Mono Project Authors |
| Noto Sans KR Regular / Bold, Version 2.004-H2 | `F_오픈소스_방화벽_최종설계서.pdf`에 필요한 글리프를 subset으로 내장하는 최종 빌드 | SIL Open Font License 1.1. 2014-2021 Adobe, Reserved Font Name `Source` |

Archify의 실제 설치 LICENSE·package.json·skill-release.json·THIRD_PARTY_NOTICES와 생성 HTML을 읽어 확인했다. Noto Sans KR는 사용 파일의 이름 테이블과 라이선스 메타데이터를 확인했으며, 아래 공식 OFL 원문과 저작권·라이선스 표시가 일치한다. 단순히 폰트 파일명이나 `fsType` 값만으로 권리를 추정한 것이 아니다.

Noto Sans KR의 원본 TTF 파일은 별도 배포하지 않는다. 문서에 필요한 subset의 PDF 내장과 폰트 파일 자체의 독립 배포는 구분한다. OFL은 문서 내장과 subset을 허용하며 그 때문에 문서 자체의 라이선스가 OFL로 바뀌지 않는다. [OFL FAQ 1.11–1.14](https://openfontlicense.org/ofl-faq/)

JetBrains Mono WOFF2 데이터는 HTML 안에 실제 포함되므로 글꼴 고지를 유지한다. 해당 HTML에는 OFL 원문과 subset 해시가 이미 포함되어 있다. 이번 패키지는 검증된 HTML 바이트를 유지하고 이 고지 파일을 함께 배포하여 Archify MIT 원문과 저작권 표시를 제공한다. HTML을 패키지에서 분리해 재배포할 때도 이 파일을 동봉하거나 동일한 고지를 HTML 안에 보존해야 한다. HTML만 고지 없이 따로 배포하지 않는다.

이번 구성도 입력은 일반 컴포넌트 아이콘과 자체 라벨을 사용하며 별도 기술 브랜드 마크를 선택하지 않는다. Archify 도구 패키지에 선택적으로 포함된 모든 브랜드 자산을 이번 결과물에 사용한 것으로 주장하지 않는다. 향후 브랜드 로고를 추가하면 해당 로고의 개별 저작권·상표 조건을 추가로 확인한다.

## 2. 출처

- [Archify 저장소](https://github.com/tt-a1i/archify) — 이번 고지의 정확한 MIT 원문은 사용한 로컬 2.17.0-dev.1 패키지의 LICENSE에서 가져왔다.
- [JetBrains Mono 저장소](https://github.com/JetBrains/JetBrainsMono) — 사용한 Archify 패키지의 `assets/JetBrainsMono-OFL.txt`와 생성 HTML의 글꼴 고지를 대조했다.
- [Google Fonts Noto Sans KR OFL 원문](https://raw.githubusercontent.com/google/fonts/main/ofl/notosanskr/OFL.txt) — 2026-10-30에 취득한 원문을 아래 그대로 수록한다.
- [SIL Open Font License 공식 안내](https://openfontlicense.org/) 및 [공식 FAQ](https://openfontlicense.org/ofl-faq/).

생성 도구가 빌드 중 사용했다는 사실과 그 도구 코드가 결과물에 포함됐다는 사실은 같지 않다. 아래 고지는 실제 내장 코드·글꼴을 대상으로 하며, 빌드 도구의 모든 개발 의존성을 결과물의 런타임 의존성으로 열거하지 않는다. 최종 PDF 검수에서는 의도한 Noto Sans KR subset만 사용되는지 실제 폰트 목록을 확인한다.
