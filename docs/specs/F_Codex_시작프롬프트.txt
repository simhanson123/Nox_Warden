Windows/Windows Server, macOS, Linux에 각각 직접 설치하는 제품이다. Linux VM이나 웹 UI만으로 Windows/macOS 지원을 대신하지 마라. macOS는 Network Extension을 사용하고 널리 배포할 제품에 PF를 대체 backend로 넣지 마라. 네이티브 테스트 환경이 없으면 pure/contract/UI 작업을 계속하고 OS 시험은 NOT RUN으로 남겨라. 실험하지 않은 strict expiry/fail-closed를 지원됨으로 표시하지 마라.

대시보드는 요청·승인·정책·적용·경로·만료·복구·감사를 모두 연결하고, AI Agent도 같은 증거를 읽기 전용 API로 조회하게 하라. 의도한 경로와 관측한 통신을 구분하라. 6개 언어, Apache-2.0, 기본 OFF인 선택 통계, 자발적 후원을 지켜라. 공개 이름은 아직 확정하지 않았으므로 fw_* 식별자로 진행하라.

기존 파일을 검토하고 실제 구현·테스트를 수행하라. 계획만 내고 끝내지 마라. 매 작업의 완료 조건을 충족한 뒤 다음 의존 작업으로 진행하라. 실제로 필요한 계정·기기·서명 자격이 없을 때는 정확한 제약과 완료된 독립 작업을 기록하라. 사용자가 별도로 요청하지 않은 운영 방화벽 변경, 유료 클라우드 자원 생성, 공개 배포, Sponsors 소개글 작성은 하지 마라.
